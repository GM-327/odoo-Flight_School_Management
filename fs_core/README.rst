======================
Flight School Settings
======================

Central configuration module for the Military Flight School Management System.

This module defines shared security groups, central configuration settings, the
Flight School application category, and base configuration records used by the
other Flight School modules.

Installation
============

Install this module before the other Flight School modules.

Configuration
=============

Use the Flight School settings menu to configure shared defaults and security
groups.

Usage
=====

Other Flight School modules depend on this module for shared settings, security,
and menu structure.
