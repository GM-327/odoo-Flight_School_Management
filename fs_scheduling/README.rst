========================
Flight School Scheduling
========================

Flight mission scheduling and timeline management for the Military Flight
School Management System.

This module provides tools for scheduling flight missions for students,
instructors, pilots, and aircraft. It includes planning wizards, timeline
views, eligibility checks, route management, and configurable scheduling
settings.

Installation
============

Install this module from the Apps menu after installing its dependencies,
including Flight School Core, Training, Fleet, People, Mail, and Web Timeline.

Configuration
=============

Configure cancellation reasons, pilot functions, flight routes, scheduling
sequences, and buffer times from the Flight School Scheduling menus and
settings.

Usage
=====

Use the scheduling menus and batch scheduling wizard to build scheduled
flights, assign crews, select aircraft, manage routes, and review planned
missions in timeline views.

Known issues / Roadmap
======================

* Scheduling performance should be monitored for large daily planning batches.
* Some frontend timeline behavior depends on the installed Web Timeline module.
