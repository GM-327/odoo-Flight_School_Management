======================
Flight School Training
======================

Training classes, enrollments, and flight missions for the Military Flight
School Management System.

This module manages class types, class requirements, flight disciplines, flight
types, flight activities, training classes, student enrollments, mission
completion, and training progress.

Installation
============

Install this module from the Apps menu after installing Flight School Core,
People, Fleet, and Mail.

Configuration
=============

Configure class types, requirements, disciplines, activities, missions, and
training settings from the Flight School Training menus.

Usage
=====

Use the training dashboard and training menus to manage classes, enrollments,
missions, progress tracking, and administrative training tasks.
