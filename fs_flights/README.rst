======================
Flight School Flights
======================

Daily flight operations monitoring and execution logging for the Military
Flight School Management System.

This module provides the operations board, simulator operations board, flight
execution records, cancellation support, schedule import, and hour distribution
tools.

Installation
============

Install this module after Flight School Scheduling, Fleet, Training, People,
Mail, and Bus.

Configuration
=============

Configure operations board pagination, refresh behavior, and flight execution
settings from the Flight School Flights settings menu.

Usage
=====

Use the daily operations and simulator operations boards to monitor flights,
enter actual departure and arrival times, complete flights, cancel flights, and
recalculate distributed hours.
