=======================
Flight School Documents
=======================

Document management for the Military Flight School Management System.

This module manages document types, uploaded files, document versions, expiry
tracking, and links to students, instructors, pilots, training classes, class
types, and administrative tasks.

Installation
============

Install this module from the Apps menu after installing its dependencies.

Configuration
=============

Configure document types and entity links from the Flight School Documents
menus.

Usage
=====

Use the document dashboard, document records, and upload wizard to manage files,
preview current versions, and synchronize expiry data with related records.
