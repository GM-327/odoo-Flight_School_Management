====================
Flight School People
====================

Personnel management for the Military Flight School Management System.

This module provides configuration and operational records for flight school
personnel, including military ranks, instructors, students, pilots, and
administrative staff. Personnel can optionally be linked to Odoo user accounts
for system access.

Installation
============

Install this module from the Apps menu after installing its dependencies.

Configuration
=============

Configure ranks, license types, qualification types, English levels, medical
classes, and people settings from the Flight School People menus.

Usage
=====

Use the People dashboard and personnel menus to manage instructors, students,
pilots, administrative staff, qualifications, and instructor availability.

Known issues / Roadmap
======================

* Dashboard KPI computations may need further aggregation optimization for very
  large datasets.
* Some dashboard labels and action names may need additional translation work.
