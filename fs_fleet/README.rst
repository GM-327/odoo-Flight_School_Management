===================
Flight School Fleet
===================

Aircraft fleet management for the Military Flight School Management System.

This module manages aircraft categories, aircraft types, individual aircraft,
availability status, airframe hours, Hobbs hours, and maintenance awareness.

Installation
============

Install this module from the Apps menu after installing Flight School Core.

Configuration
=============

Configure aircraft categories, aircraft types, and fleet settings from the
Flight School Fleet menus.

Usage
=====

Use the fleet dashboard and aircraft menus to track aircraft readiness,
maintenance state, and available fleet resources.
